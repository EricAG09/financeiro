# Seed

Sem dados de seed até aqui — e nenhum dado financeiro fictício será adicionado.

O que faz sentido semear quando o banco existir:

- categorias padrão de `src/shared/constants/categories.ts`, criadas para cada novo usuário
  (preferencialmente por trigger, não por script de seed);
- nada mais.

Valores financeiros de exemplo não entram no repositório nem no banco: em um app
de dinheiro, dado falso indistinguível de dado real é um risco, não uma
conveniência.
